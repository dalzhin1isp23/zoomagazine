# ZooMagazine — Frontend

Frontend-часть интернет-магазина товаров для животных.

Проект разрабатывался в рамках дипломной работы и представляет собой клиентское приложение с каталогом товаров, корзиной, авторизацией пользователей, личным кабинетом и административной панелью.

## Возможности

* просмотр каталога товаров;
* навигация по категориям;
* просмотр информации о товарах;
* работа с корзиной;
* регистрация и авторизация пользователей;
* личный кабинет;
* административная панель;
* страницы дополнительной информации о магазине.

## Страницы

| Страница                  | Маршрут         |
| ------------------------- | --------------- |
| Главная                   | `/`             |
| Каталог                   | `/products`     |
| Корзина                   | `/cart`         |
| Профиль                   | `/profile`      |
| Регистрация / авторизация | `/registration` |
| Административная панель   | `/admin`        |

## Технологии

* TypeScript
* React
* Vite
* HTML / CSS

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/dalzhin1isp23/zoomagazine.git
```

Перейдите в папку проекта:

```bash
cd zoomagazine
```

Установите зависимости:

```bash
npm install
```

Запустите проект в режиме разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, указанному Vite в терминале.
